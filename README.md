# RSA 加密教學平台

一個互動式的 RSA 加密教學網頁應用程式，幫助學習者從零開始理解 RSA 加密的原理和應用。

## 📚 專案簡介

這是一個全端（Full-stack）教學平台，包含：

- 🎓 **互動式教學投影片**：26 頁精心設計的教學內容，涵蓋古典密碼學、對稱式加密、非對稱式加密到 RSA 完整原理
- 👑 **古典密碼工具**：互動式凱薩密碼加密/解密工具，體驗暴力破解過程
- 🧮 **RSA 計算器**：實際操作 RSA 加密解密流程，理解每個步驟的數學運算
- ✏️ **測驗系統**：透過測驗驗證學習成效，並追蹤答題統計
- 📊 **進度追蹤**：記錄學習進度，隨時查看完成狀態

## 🏗️ 技術架構

### 前端
- **React 18** - 現代化的 UI 框架
- **Vite** - 快速的開發建置工具
- **Axios** - HTTP 請求處理
- **CSS3** - 精美的響應式設計

### 後端
- **Node.js** - JavaScript 執行環境
- **Express** - Web 應用框架
- **Better-SQLite3** - 輕量級資料庫

### 資料庫
- **SQLite** - 儲存用戶進度、測驗記錄和練習歷史

## 📦 安裝步驟

### 前置需求
- Node.js 18 或更高版本
- npm 或 yarn

### 1. 安裝後端依賴

```bash
cd backend
npm install
```

### 2. 安裝前端依賴

```bash
cd frontend
npm install
```

## 🚀 啟動專案

### 開發模式

需要同時啟動前端和後端：

#### 啟動後端伺服器（終端 1）

```bash
cd backend
npm start
```

後端將運行在 `http://localhost:3000`

#### 啟動前端開發伺服器（終端 2）

```bash
cd frontend
npm run dev
```

前端將運行在 `http://localhost:5173`

打開瀏覽器訪問 `http://localhost:5173` 即可使用應用程式。

## 📖 功能說明

### 1. 教學投影片

- 26 頁完整的密碼學教學內容
- **古典密碼學**：凱薩密碼、密碼學歷史
- **對稱式加密**：AES 加密標準、密鑰分發問題
- **非對稱式加密**：RSA 原理與應用、混合式加密
- **數學基礎**：質數、質因數分解、模運算
- 從「什麼是加密」到「RSA 實際應用」完整涵蓋
- 支援目錄快速跳轉
- 自動記錄學習進度

### 2. 古典密碼工具

**凱薩密碼互動工具**
- 加密/解密功能
- 即時顯示字母對照表
- 暴力破解演示（嘗試所有 25 種可能）
- 移位數調整（1-25）
- 直觀理解古典密碼的弱點

### 3. RSA 計算器

**步驟一：生成金鑰對**
- 選擇兩個質數 p 和 q
- 系統提供建議的質數對
- 自動計算公鑰和私鑰

**步驟二：加密訊息**
- 輸入要加密的數字
- 使用公鑰進行加密
- 顯示加密公式和結果

**步驟三：解密訊息**
- 使用私鑰解密密文
- 顯示解密公式和結果
- 驗證解密結果是否正確

**特色功能：**
- 質數檢查
- 練習歷史記錄
- 詳細的計算步驟展示

### 4. 測驗系統

- 8 道精選測驗題目（涵蓋古典密碼、對稱式、非對稱式加密）
- 即時反饋答題結果
- 詳細的答案解釋
- 累計答題統計
- 答題回顧功能

### 5. 進度追蹤

- 視覺化進度圓環
- 已完成/總投影片統計
- 完成所有課程時顯示祝賀徽章

## 🔌 API 端點

### 用戶相關
- `POST /api/users` - 建立或取得用戶
- `GET /api/users/:userId` - 取得用戶資訊

### 進度相關
- `POST /api/progress` - 更新學習進度
- `GET /api/progress/:userId` - 取得學習進度

### 測驗相關
- `POST /api/quiz` - 提交測驗答案
- `GET /api/quiz/stats/:userId` - 取得測驗統計

### RSA 計算相關
- `GET /api/rsa/is-prime/:number` - 檢查是否為質數
- `GET /api/rsa/primes` - 生成質數列表
- `POST /api/rsa/generate-keys` - 生成 RSA 金鑰對
- `POST /api/rsa/encrypt` - RSA 加密
- `POST /api/rsa/decrypt` - RSA 解密
- `GET /api/rsa/suggested-pairs` - 取得建議的質數對
- `POST /api/rsa/practice` - 儲存練習記錄
- `GET /api/rsa/practice/:userId` - 取得練習歷史

## 🛠️ 開發相關

### 建置生產版本

#### 前端建置

```bash
cd frontend
npm run build
```

建置後的檔案會在 `frontend/dist` 目錄下。

#### 部署建議

1. 前端可以部署到任何靜態網站託管服務（如 Vercel、Netlify）
2. 後端需要 Node.js 環境（如 Heroku、Railway、DigitalOcean）
3. 確保前端的 API 請求指向正確的後端 URL

### 環境變數

前端可以設定以下環境變數（在 `.env` 檔案中）：

```
VITE_API_URL=http://localhost:3000/api
```

## 📝 教學內容大綱

### 密碼學基礎（1-3）
1. 什麼是 RSA？從零開始的加密世界
2. 為什麼需要加密？（情境篇）
3. 日常生活中的加密需求

### 古典密碼學（4-6）
4. 密碼學的歷史：古典密碼學
5. 古典密碼學：凱薩密碼
6. 為什麼古典密碼不夠安全？

### 對稱式加密（7-9）
7. 現代密碼學：對稱式加密（同一把鑰匙）
8. 對稱式加密：AES（進階加密標準）
9. 對稱式加密的密鑰分發問題

### 非對稱式加密（10-12）
10. 現代密碼學：非對稱式加密（兩把不同的鑰匙）
11. 非對稱式加密的應用：混合式加密
12. RSA 的核心想法（白話版）

### RSA 數學基礎（13-14）
13. RSA 需要的數學概念（一）：質數是什麼？
14. RSA 需要的數學概念（二）：乘法容易，拆解困難

### RSA 金鑰生成（15-18）
15. RSA 金鑰產生流程（步驟一）：選兩個質數
16. RSA 金鑰產生流程（步驟二）：計算 n
17. RSA 金鑰產生流程（步驟三）：計算 φ(n)
18. RSA 金鑰產生流程（步驟四）：產生公鑰和私鑰

### RSA 加密解密（19-21）
19. 加密流程示範（把訊息鎖起來）
20. 解密流程示範（用鑰匙打開）
21. 完整流程回顧

### RSA 應用與總結（22-26）
22. 為什麼 RSA 難被破解？
23. RSA 的實際應用
24. 常見問題與迷思 Q&A
25. 總結
26. 小測驗
